# KYOTABI＋

京都で次に行く場所を、写真から探すアプリです。関西ビギナーズハッカソン vol.8（2026年8月）で制作しました。

## 概要

KYOTABI＋は、京都を訪れた人が、まだ知らない場所や過ごし方を見つけるためのWebアプリです。投稿一覧では正確な場所を伏せ、写真とタイトルから気になる体験を選べます。

- キーワード、気分、天気、空き時間、予算などから投稿を探せます。
- 初回に10ptを受け取り、1ptで投稿の本文と場所、Googleマップのリンクを開けます。
- 写真を添えて投稿できます。写真に位置情報があれば場所の入力に利用できます。
- 投稿は共有データベースから取得します。ポイントや閲覧履歴などはログインなしで、利用中のブラウザに保存します。

ハッカソン時の[公開デモURL](https://kyoto-repeater.vercel.app/)も残しています。制作当時の要件と作業記録は [`.docx` フォルダー](.docx/)に保存しています。

## インストール

Node.js と npm を用意し、次のコマンドを実行します。

```bash
git clone https://github.com/OgawaTatsukicreator/kyoto_Beginners_hackathon_vol1.git
cd kyoto_Beginners_hackathon_vol1
npm ci
```

基本的な起動に追加設定は不要です。写真の位置情報から施設名や住所を自動入力したい場合だけ、ルートに `.env.local` を作り、`GOOGLE_MAPS_API_KEY` を設定してください。未設定なら座標の表示または手入力に切り替わります。`.env.local` はGitの管理対象外です。

## 使い方

1. `npm run dev` で開発サーバーを起動し、ブラウザで <http://localhost:3100> を開きます。
2. 最初の画面で行ったことのある場所を選ぶか、「あとで」からホームへ進みます。ホームで投稿を選び、必要に応じて「かんたん検索」で条件を指定します。
3. 投稿の続きと場所を読むときは「1pt を使って読む」を押します。下部の「投稿」から新しい投稿を作り、「プロフィール」で自分の投稿と読んだ投稿を確認できます。

位置情報から地名を取得するAPIの呼び出し例です。APIキーがない場合、レスポンスは `204` になります。

```js
const response = await fetch('/api/reverse-geocode?lat=35.0116&lng=135.7681');
const place = response.status === 204 ? null : await response.json();
console.log(place?.name ?? '地名を取得できませんでした');
```

共有データベースに接続できないときも、同梱の投稿を閲覧できます。ブラウザ内のポイントや閲覧履歴は別の端末に引き継がれません。

## 運用

1. このリポジトリをフォークし、変更用のブランチを作成します。
2. 変更後に `npm run build` でビルドを確認します。公開用にローカルで動作を確かめる場合は `npm run start` を実行します。
3. 変更内容と確認結果を記載して、`main` ブランチ宛てにプルリクエストを送信します。
